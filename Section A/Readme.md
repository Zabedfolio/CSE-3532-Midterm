1. What is the purpose of DNS in Internet communication?
DNS changes a website name like google.com into an IP address that computers can understand.

2. Explain how HTTP works between a client and a server.
The browser sends a request to the server using HTTP, and the server sends back a response like HTML, CSS, or data.

3. Define the client–server model.
The client asks for a service, and the server gives the service or data.

4. What is the difference between GET and POST requests?
GET sends data in the URL and is used to read data. POST sends data in the request body and is used to submit data.

5. What are the main components of a web page?
The main parts are HTML for structure, CSS for design, and JavaScript for behavior.

6. What is HTML? Why is it called a markup language?
HTML is the language used to create web pages. It is called a markup language because it uses tags to mark content.

7. Differentiate between inline, internal, and external CSS.
Inline CSS is written inside one tag, internal CSS is written inside a <style> tag, and external CSS is written in a separate .css file.

8. What are semantic tags in HTML? Give two examples.
Semantic tags clearly describe the meaning of content. Examples: <header> and <article>.

9. Explain the CSS Box Model with a diagram.
The box model has 4 parts: content, padding, border, and margin.[content] -> [padding] -> [border] -> [margin]

10. What is Tailwind CSS? Why is it called a utility-first framework?
Tailwind CSS is a CSS framework with ready-made utility classes. It is called utility-first because you style by adding small classes directly in HTML.

11. What are classes and IDs in CSS?
A class can be used on many elements, but an ID should be unique for one element.

12. What is DOM in JavaScript?
DOM means Document Object Model. It is the tree-like structure of HTML that JavaScript can read and change.

13. Explain what JavaScript events are with examples.
Events are actions like click, input, or submit. Example: a button click event.

14. What is the difference between let, const, and var?
let is for values that can change, const is for values that should not change, and var is the older way to declare variables.

15. Define a JavaScript object and mention its advantages.
An object stores related data using key-value pairs. It is useful for organizing information clearly.

16. What are data types in JavaScript?
Common data types are string, number, boolean, object, array, null, and undefined.

17. What are loops used for in JavaScript?
Loops repeat code many times, so they are useful for lists, counts, and repeated tasks.

18. What is meant by a responsive web design?
Responsive design means the webpage changes nicely on different screen sizes like mobile, tablet, and desktop.

19. Define IP address and its importance.
An IP address is a unique number for a device on a network. It helps devices find and communicate with each other.

20. What are HTTP status codes? Give two examples.
HTTP status codes show the result of a request. Examples: 200 means success, 404 means page not found.

21. Explain the concept of front-end and back-end in web applications.
Front-end is what users see in the browser. Back-end is the server side that handles data, logic, and database work.

22. What is a web browser? Mention its main functions.
A web browser is software used to open websites. It requests web pages, displays content, and runs JavaScript.

23. Explain internal and external JavaScript linking.
Internal JavaScript is written inside the same HTML file in a <script> tag. External JavaScript is written in a separate .js file.

24. What is the purpose of the <meta> tag in HTML?
The meta tag gives extra information about the page, such as character set and viewport settings.

25. Explain how CSS Flexbox helps in layout design.
Flexbox helps arrange items in a row or column and makes alignment, spacing, and centering very easy.
